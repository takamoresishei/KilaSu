# Code of conduct

Treat contributors and users with respect. Technical disagreement is welcome;
personal attacks, harassment, discrimination, threats, doxxing and exposing
private credentials or device data are not.

Discuss implementation and evidence rather than attacking people. Give useful
reproduction details, respect the scope of a review, and accept corrections.
Maintainers may remove abusive content or restrict participation. Appeal through
a private GitHub contact channel available on the maintainer profile.
